# AI-asistovaný softwarový vývoj – Agentické inženýrství a harness DarkFactory

`DarkFactory/` is the canonical book root.

## Structural contract

- Folder manifests own numbered structural reading order.
- Top-level chapters are exactly: Úvod; Jazykový model; Harness; AI-asistovaný vývoj a agentické inženýrství; DarkFactory; Vyhodnocení; Závěr.
- No Theory/Practical wrapper chapters exist.
- Subject chapters own unheaded opening framing and optional unheaded closing synthesis; framing is not a semantic term and never creates an outline entry.
- Semantic articles are unnumbered, excluded from the school PDF contents, and remain available to the richer web Structure index.
- Manifest order is the only reading-order authority. Semantic relations are independent metadata.
- Section-owned semantic terms have the same definition/description/examples/practical/relations/source capability as file-backed concepts.
- Chapter 5 is reserved for canonical autogenerated DarkFactory documentation; no parallel manual architecture/lifecycle narrative is maintained.

## Semantic article contract

Theory articles render in this order:

1. `definition` — what it is;
2. `description` — how it works / why it matters;
3. `examples` plus `visual` / `attachments` where appropriate;
4. `practical` — what the concept means in practice for agentic software development.

The fields are semantic data, not visible numbered subsections.

Detailed ownership, terminology, sourcing, hierarchy, and validation rules live in the repository-root `AGENTS.md`.
