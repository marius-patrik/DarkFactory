# DarkFactory book root

`DarkFactory/` je kompletní book root práce **DarkFactory: Agentic Engineering in practice (Agentické inženýrství v praxi)**.

## Structural contract

- Folder manifest = číslovaná strukturální hierarchie.
- Concept = nečíslovaný sémantický článek.
- Strukturální section může vlastnit `term` / `keyword`, pokud je sama jediným vlastníkem daného konceptu.
- Sémantický graf je oddělen od folder hierarchy.
- Podporované vztahy: `dependency`, `related`, `parent`, `child`.
- Každý fakt, mechanismus, definice, příklad a evidence má jednoho kanonického vlastníka.
- Úvod sekce rámuje; Závěr syntetizuje. Ani jeden neopakuje child články.
- `3.2 DarkFactory` je záměrně prázdný slot pro autogenerated DarkFactory docs.

## Terminology

Jediná API pole jsou:

- `term`
- `keyword`

Alespoň jedno je povinné.

Výstup je pouze `term`, `term (keyword)`, nebo `keyword`.

`keyword != none` řídí zároveň front-matter Klíčová slova i Encyklopedii/rejstřík.

Staré `industry`, `czech`, `english`, `alias` ani boolean `keyword` se nesmí vracet.

## Theory boundary

- **AI-asistovaný vývoj**: jak AI mění zadání, změnu a ověřování softwarové práce.
- **Jazykový model a inference**: co model a inferenční engine skutečně provádějí a jaké mají limity.
- **Harness**: stav, agentní smyčka, nástroje, prostředí a rozšiřitelnost kolem inference.
- **Agentické inženýrství**: návrh kontextu, řízení agentního chování a orchestrace nad Harnessem.

Podrobná kanonická struktura, psací pravidla a single-owner pravidlo jsou v kořenovém `AGENTS.md`.
