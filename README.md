# AI-asistovaný softwarový vývoj – Agentické inženýrství a harness DarkFactory

Typst-first thesis source with a React/TypeScript review workbench. The canonical publication is built from semantic records and explicit folder manifests; manuscript reading order is authored only by manifests.

## Canonical manuscript structure

1. Úvod
2. Jazykový model
   - 2.1 Architektura a reprezentace
   - 2.2 Inference
3. Harness
   - 3.1 Smyčka a stav
   - 3.2 Prostředí a nástroje
   - 3.3 Rozšíření
4. AI-asistovaný vývoj a agentické inženýrství
   - 4.1 Zadání a způsob práce
   - 4.2 Řízení změny
   - 4.3 Kvalita a ověřování
   - 4.4 Instrukce a kontext
   - 4.5 Řízení agentního chování
   - 4.6 Orchestrace agentů
5. DarkFactory
6. Vyhodnocení
   - 6.1 Ověření mechanismů
   - 6.2 Ověření systému
   - 6.3 Ověření na repozitářích
   - 6.4 Výzkumné otázky
   - 6.5 Diskuse a omezení
7. Závěr

There are no Theory/Practical wrapper chapters. Chapters 2–4 are the theoretical literature-backed body; Chapters 5–6 are the practical project/evidence body.

Structural sections render their opening framing immediately after the numbered heading and may render an unheaded closing synthesis after their children. Semantic concept articles are visible and linkable but unnumbered and excluded from the school PDF contents; the web Structure pane uses the semantic HTML heading index and can expose them independently.

Theory semantic articles use the canonical contract `definition → description → examples/visuals → practical`. Relations form a semantic graph only; they never determine reading order. Section-owned semantic terms such as Harness have the same semantic fields as file-backed concepts.

Chapter 5 is reserved for the full canonical autogenerated DarkFactory documentation. No parallel hand-maintained DarkFactory architecture or lifecycle narrative is maintained.

## Build

```bash
make all BOOK=DarkFactory
make ci BOOK=DarkFactory
```

See `AGENTS.md` for the durable manuscript/schema contract and `PLAN.md` for coordinating execution state.
