The introduction owns contemporary adoption/capability evidence and the Vibe Coding → Agentic Engineering motivation. Theory explains model, inference, and harness mechanisms. Practical explains Agentic Engineering practices and their realization in DarkFactory. Results and discussion own observed evaluation evidence.

Semantic concept articles remain visible and linkable but unnumbered and excluded from the school PDF contents. They use the canonical contract:

`definition → description → examples/visuals → practical`

Relations form a semantic graph only; manifests define reading order.

DarkFactory architecture/system description is sourced from the canonical autogenerated DarkFactory documentation rather than a parallel hand-maintained lifecycle narrative.
