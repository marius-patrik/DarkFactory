# DarkFactory-Paper

Odborná práce **DarkFactory: Agentické inženýrství v praxi**.

Repozitář obsahuje konceptově řízený Typst rukopis, publikační šablony, webový viewer a submodule praktického systému DarkFactory.

## Argument a struktura

Argument práce je vlastněn Úvodem:

**jak AI mění vývoj softwaru → co model skutečně je a dokáže → co kolem něj přidává Harness → jak se tyto mechanismy záměrně skládají do agentního chování → jak je realizuje DarkFactory → co o výsledku ukazují důkazy**

Folder manifesty `index.typ` jsou jediným zdrojem dokumentové hierarchie.

1. Úvod
2. Teoretická část: Agentické systémy ve vývoji softwaru
   - AI-asistovaný vývoj
   - Jazykový model a inference
   - Harness
   - Agentické inženýrství
3. Praktická část
   - Úvod
   - DarkFactory
   - Životní cyklus změny
   - Vyhodnocení
4. Závěr

Sekce jsou číslované. Sémantické články jsou nečíslované, ale zůstávají v obsahu. Strukturální sekce může sama vlastnit sémantický termín, pokud by samostatný článek pouze duplikoval stejný význam.

Část **3.2 DarkFactory** je v hand-maintained rukopisu záměrně prázdná; její kanonický obsah má být převzat z autogenerated DarkFactory dokumentace.

## Terminologie

Sémantická položka má pouze:

- volitelný `term`;
- volitelný `keyword`.

Alespoň jedno pole musí existovat.

Rendering:

- `term` → `term`
- `term + keyword` → `term (keyword)`
- `keyword` → `keyword`

`keyword != none` zároveň určuje zařazení do Klíčových slov a Encyklopedie/rejstříku.
