# DarkFactory-Paper — Active Completion Plan

This plan tracks the currently executing restructure. Durable rules live in `AGENTS.md`.

## Target argument

Section 1 owns the thesis argument:

**jak AI mění vývoj softwaru → co model skutečně je a dokáže → co kolem něj přidává Harness → jak se tyto mechanismy záměrně skládají do agentního chování → jak je realizuje DarkFactory → co o výsledku ukazují důkazy**

Theory and Practical must demonstrate this chain rather than restating it.
