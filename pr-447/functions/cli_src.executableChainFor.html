    • executableChainFor(route: Pick<RouteResult, "chain" | "ranked">): Candidate[]

      The candidates a run tries, in order: the router's chosen chain, then candidates it skipped only because a limit is active. They go last so the supervisor waits for their windows instead of the run ending with exit 1 when every chosen candidate turns out unusable (seen 2026-09-15: chosen models missing from live catalogs while the rate-limited ones would have recovered within a minute).
